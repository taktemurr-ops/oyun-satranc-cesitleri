# Satranç Çeşitleri · Chess Variety

Rastgele Diziliş, Üç Şah, Merkez Kralı, Piyon Ordusu, Patlayan Satranç, Kral Yarışı, Ters Satranç, Mini Satranç 5×5, 6×6 Satranç: her biri 50.000 bölüm (toplam 450.000), yapay zekâ rakipler, 33 dil. Masa Oyunları merkez uygulamasında tek kutucuk altında listelenir; ortak motor: [masa-motoru](https://github.com/taktemurr-ops/masa-motoru).
